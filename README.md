# Retail Sales Analysis

## Project Overview
Analyzed retail sales data using MySQL and Excel
to understand sales trends and customer behavior.

## Tools Used
- MySQL
- Microsoft Excel

## Analysis

- Monthly revenue
- Revenue by product category
- Revenue by gender
- Revenue by age group
- Top transactions

- Total revenue: 456,000
- Total transactions: 1,000
- Highest revenue category: Electronics
